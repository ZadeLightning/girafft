# 01 — Arduino Basics

Small, independent sketches for learning the Arduino fundamentals before introducing the RC signal chain.

- `01_blink.ino` — basic program structure and digital output.
- `02_serial_test.ino` — basic Serial communication.
- `03_servo_sweep.ino` — basic servo output using the Arduino Servo library.

Next: `T8L → ER8 → Arduino PWM input`.
