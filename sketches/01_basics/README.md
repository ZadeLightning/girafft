# 01 — Arduino Basics

Small, independent sketches for learning the Arduino development environment and basic Arduino C++ concepts before connecting the T8L/ER8 signal chain.

## Sketches

Each Arduino `.ino` sketch lives inside a folder with the same name, as required by Arduino IDE.

```text
01_basics/
├── README.md
├── 01_blink/
│   └── 01_blink.ino
├── 02_serial_test/
│   └── 02_serial_test.ino
└── 03_servo_sweep/
    └── 03_servo_sweep.ino
```

These are intentionally incremental. Each sketch should prove one concept before the next layer is added.
