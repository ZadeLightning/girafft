# Builder photos

Place selected portrait photos and videos directly in this folder. The website carousel supports `.jpg`, `.jpeg`, `.png`, `.webp`, `.mp4`, `.webm`, `.mov`, and `.m4v` files, sorted by filename. Videos autoplay muted and loop while their slide is selected. Use numbered filenames to choose a specific order, for example `01-portrait.jpg` and `02-on-the-water.mp4`.

Keep raw or alternate media in `all/`; files in that subfolder are not included in the website carousel.
