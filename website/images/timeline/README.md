# Timeline media

Each numbered folder matches one timeline chapter. Place every candidate photo or video in that chapter's `all/` subfolder. Once you've chosen the media to showcase, copy it into the numbered chapter folder itself and give it a descriptive filename.

The website automatically creates a swipeable carousel from supported image and video files directly inside each numbered folder. Files inside `all/` are kept as a collection of candidates and are not shown on the website. Filenames become the captions, so use names that make sense to visitors.

The six chapters are:

1. `01 bare hull`
2. `02 aft deck hatch`
3. `03 propeller`
4. `04 steering`
5. `05 mvp final assembly`
6. `06 mvp sea trial`

Supported formats: JPG/JPEG, PNG, WebP, GIF, MP4, WebM, MOV, and M4V. MP4/H.264 is recommended for video playback across browsers.
