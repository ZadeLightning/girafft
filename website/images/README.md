# Project imagery

Keep original project photos and videos here in descriptive subfolders. The existing hero/gallery imagery uses optimized copies in `../public/images/`; timeline media is loaded directly from the selected files in the timeline chapter folders below.

## Timeline media folders

Each build chapter has a folder under `timeline/`. Put candidate photos and clips in that chapter's `all/` subfolder. After choosing the media to display, copy the selected files into the chapter folder itself and give them descriptive filenames. The site automatically builds a swipeable carousel from supported media in each chapter folder; it ignores files inside `all/`.

`hull/giraffe-paint-concept-mockup.png` is an AI-generated concept based on a real boat photo. Treat it as a branding mockup, not a photo of the boat's current finish.
